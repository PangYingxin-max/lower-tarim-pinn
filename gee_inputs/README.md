# Processed GEE inputs

gee_inputs/tarim contains the annual Tarim corridor series and TVDI edge diagnostics. gee_inputs/ejina contains the point-consistent lower Heihe/Ejina series, TVDI edge diagnostics, point audit, and provenance.

Canonical files:

- gee_inputs/tarim/series.csv
- gee_inputs/tarim/tvdi_edges.csv
- gee_inputs/tarim/provenance.json
- gee_inputs/ejina/series.csv
- gee_inputs/ejina/tvdi_edges.csv
- gee_inputs/ejina/point_audit.csv
- gee_inputs/ejina/provenance.json

The Excel copies are retained because several scripts use openpyxl input paths. They contain the same annual variables as the CSV exports.
