# Processed data index

| File | Description |
|---|---|
| tarim_water_official_2000_2023.csv | Audited lower Tarim annual conveyance table |
| heihe_water_official_2000_2023.csv | Zhengyixia release plus East Juyan inflow where available |
| README_tarim_water.md | Row-level Tarim source notes and known gaps |
| README_heihe_water.md | Row-level Heihe source notes and the 11/24-year limitation |
| water_records_audit.csv | Comparison of archived model inputs and audited official values |
| water_records_official_2021_2023.csv | Official/derived 2021--2023 Tarim checkpoints |
| README_water_records.md | Explanation of the water-record audit |
| raw_spatial_windows/README.md | Instructions for exporting the three 10 m GeoTIFF windows |

The CSV files are the canonical tabular inputs. The provenance notes must be read together with the numbers because some records are compiled, reproduced, or derived rather than direct station downloads.
